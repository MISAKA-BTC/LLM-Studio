They do not compile Rust or launch a native Tauri window. No native installer is included.

Work-volume comparison to the phase-1 deliverable
- Same 1000 conversations, active conversation with 1000 messages, actual App/StrictMode in jsdom.
- Synthetic dimensions: transcript 600x760; sidebar height 480.
- Mounted sidebar thread rows: 1000 -> 20.
- Mounted active messages: 1000 -> 10.
- All App DOM elements: 31178 -> 680.
- Both versions retain all 1000 conversations and all 1000 active-conversation messages.
- Separate 2000-message DOM regression: 9 initially mounted messages with a 600px viewport.
- A 5000-conversation storage fixture updating one conversation serializes 5000 -> 1 conversation bodies.
- Serialized storage write values: 7489618 -> 659238 UTF-8 bytes; current and prior indexes are included.
- Cold hydration storage reads: 2 -> 5003 for that fixture. This tradeoff is recorded, not hidden.

Method limits
Storage comparisons use a capacity-unlimited in-memory Map, not browser storage/disk/IPC.
The 5000-conversation fixture may exceed real localStorage quota. Fault-injection unit tests
separately cover quota, partial writes, corruption, migration, conflicts and deletion recovery.
DOM comparisons use jsdom and synthetic dimensions, without browser layout or paint. Stored
Node/jsdom durations are instrumented local observations, not UI latency, FPS or native speed.
The native runtime, GPU generation and real WebView were not run. Chromium process startup was
blocked by the execution sandbox earlier in this conversation; no sandbox bypass was used.

Artifact contents
Full source, current ui/dist, regression tests, benchmark scripts and reports.
No node_modules, Rust target output, VSCodium source copy or native installer is included.
The Tauri architecture and runtime/backend source are unchanged by phase 2.

Known build note
Vite reports that lib/agent/run.ts has both static and dynamic importers and stays in the
shared graph. This is not a build failure. Optional math/Markdown/grammar splitting is
validated separately; the main entry itself is not claimed to be smaller.
